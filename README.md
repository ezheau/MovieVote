# 🎬 MovieVote — что смотрим сегодня?

Одностраничный сервис для компании: добавьте фильмы, которые вы собираетесь
посмотреть, и доверьтесь рулетке или устройте голосование.

Возможности:

- 🎰 **Рулетка** — случайный выбор фильма из списка, с исключением уже
  просмотренных.
- 🗳️ **Голосование** — все выбирают фильм, результаты подводятся автоматически.
- 🎥 **Поиск по Кинопоиску** — фильмы добавляются по названию с подгрузкой
  постеров и описаний.
- 🤖 **ИИ-ассистент** — подсказки от нейросети (Claude / z.ai / OpenAI /
  DeepSeek) через встроенный прокси.

## Запуск

Нужен Python 3 (без зависимостей — только стандартная библиотека):

```bash
python server.py          # порт 8765 по умолчанию
python server.py 8080     # или свой порт
```

Откройте <http://127.0.0.1:8765/index.html>.

## Ключи API

Ключи сервисов (Кинопоиск, ИИ-провайдеры) можно ввести прямо на странице
в настройках — они хранятся в браузере. Либо создайте файл `env` рядом с
`index.html` по образцу:

```
# База фильмов ПоискКино — токен выдаёт Telegram-бот @poiskkinodev_bot
KP_TOKEN=

# ИИ-провайдеры (достаточно одного)
ZAI_TOKEN=
OPENAI_TOKEN=
DEEPSEEK_TOKEN=
```

Файл `env` автоматически подхватывается локальным сервером и не публикуется
(исключён через `.gitignore`).

## Как это устроено

- `index.html` — всё приложение в одном файле (разметка, стили, логика).
- `server.py` — локальный сервер: раздаёт статику и проксирует запросы к
  ИИ-провайдерам (браузеры блокируют прямые запросы из-за CORS, а некоторые
  хосты недоступны без VPN). Слушает только `127.0.0.1`, ключ передаётся
  дальше без изменений и нигде не сохраняется.
- `testdata/` — мок-данные и скрипты для тестов без реальных API.
